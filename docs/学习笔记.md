说一下目前简单的流程 
1、main服务启动一个gin服务器
2、建一个router 路由文件存储路由地址
``` go
func Router() *gin.Engine {
        r := gin.Default()
        user := r.Group("/user")
        return r
}
```

然后按照对应路由 写一个controller
```go
        user.GET("/user/SelectLists", (&controllers.UserController{}).SelectLists)
		user.GET("/user/info", controllers.UserController{}.SelectUserSuccess)
```

路由（类似于controller）调用controller （类似于service）
controller调用model （类似于mapper）
然后model调用dao访问数据库

c.Param("id") // 匹配 /SelectUserIdToName/3
